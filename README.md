## 🚀 GitHub Pages

Deployment otomatis disiapkan melalui workflow `.github/workflows/pages.yml`. Setiap push ke branch `main` menjalankan proses publikasi menggunakan GitHub Actions.

Jika situs belum tampil, buka **Settings → Pages** pada repository dan pastikan **Build and deployment → Source** menggunakan **GitHub Actions**. Setelah workflow berhasil, buka tautan GitHub Pages di atas. Publikasi pertama dapat memerlukan beberapa menit.

## 🛠️ Pengembangan

Edit `index.html`, lalu commit dan push perubahan ke branch `main`. Tidak diperlukan instalasi dependency untuk website statis ini.
